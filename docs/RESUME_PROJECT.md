# Resume Project Details

## Food Delivery Platform

**Full Stack Developer**

*A production-ready full-stack food delivery application facilitating restaurant discovery, dynamic cart management, and seamless order processing.*

**Tech Stack:** React, Next.js, TypeScript, Node.js, Express, PostgreSQL, Prisma, Tailwind CSS

- Architected a decoupled full-stack architecture using Next.js for a highly responsive frontend and Express/Node.js for a robust RESTful API.
- Implemented secure, stateless JWT authentication with role-based access control (RBAC), isolating customer data and admin functionalities.
- Engineered a transactional checkout workflow using Prisma to guarantee data integrity across carts and historical order price snapshots.
- Designed a dynamic, interactive UI with Tailwind CSS and Framer Motion, delivering a polished user experience including real-time cart updates and complex search/filtering capabilities.
- Deployed the unified system via Vercel (Frontend) and Render (Backend), implementing UX fallbacks to gracefully handle cloud cold-start latencies.
